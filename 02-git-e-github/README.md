# 02 — Git e GitHub

## Objetivo

Praticar versionamento básico com um repositório local de estudos.

## Nível

Iniciante.

## Pré-Requisitos

- Git instalado.
- Noções de terminal.

## Ambiente Autorizado

Uma pasta local criada por você. GitHub é opcional e deve ser usado apenas com conteúdo público e seguro.

## Ferramentas

- Git.
- Editor de texto.
- Terminal.

## Passos

1. Crie uma pasta `lab-git`.
2. Inicialize um repositório Git.
3. Crie `README.md`.
4. Escreva objetivo do laboratório.
5. Execute `git status`.
6. Adicione o arquivo ao staging.
7. Faça um commit com mensagem clara.
8. Crie uma branch `docs/anotacoes`.
9. Adicione `anotacoes.md`.
10. Faça novo commit.
11. Compare o histórico com `git log --oneline`.

## Perguntas de Reflexão

- O que mudou entre working tree, staging e commit?
- Por que commits pequenos ajudam revisão?
- Que tipo de dado não deve ir para um repositório público?

## Resultado Esperado

Você terá praticado um fluxo básico de versionamento e branch.

## Encerramento ou Limpeza

Remova a pasta se desejar. Se publicar no GitHub, revise antes para garantir que não há dados sensíveis.

## Limites Éticos e Legais

Nunca publique senhas, tokens, arquivos `.env`, chaves privadas ou dados pessoais.
