# 00 — Ambiente e Segurança

## Objetivo

Preparar um ambiente de estudos seguro e definir escopo antes de qualquer prática.

## Nível

Iniciante.

## Pré-Requisitos

- Computador próprio.
- Noções básicas de arquivos e pastas.
- Leitura de [SAFETY.md](../SAFETY.md).

## Ambiente Autorizado

Somente sua máquina local e arquivos criados por você para este laboratório.

## Ferramentas

- Editor de texto.
- Terminal.
- Navegador.
- Git opcional.

## Passos

1. Crie uma pasta chamada `k0sec-labs`.
2. Dentro dela, crie `anotacoes.md`.
3. Escreva o objetivo dos seus estudos.
4. Crie uma seção chamada `Escopo autorizado`.
5. Liste quais ambientes você pode usar com segurança.
6. Crie uma seção chamada `Fora de escopo`.
7. Liste o que você não deve testar.
8. Leia novamente [SAFETY.md](../SAFETY.md).

## Perguntas de Reflexão

- O que significa autorização explícita?
- Quais riscos existem ao testar sistemas de terceiros?
- Como registrar aprendizado sem expor dados sensíveis?

## Resultado Esperado

Você terá uma pasta organizada e um documento com limites claros de prática.

## Encerramento ou Limpeza

Mantenha a pasta para os próximos laboratórios. Não adicione dados sensíveis.

## Limites Éticos e Legais

Este laboratório não envolve testes técnicos em sistemas. Ele existe para criar consciência de escopo e segurança.
