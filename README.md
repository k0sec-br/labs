# K0Sec Labs

Laboratórios educacionais da K0Sec para praticar tecnologia e cibersegurança de forma segura, ética e autorizada.

Este repositório é voltado a exercícios práticos introdutórios. Ele não contém alvos reais, instruções de abuso ou atividades contra terceiros.

**Slogan da K0Sec:** Learn. Explore. Defend.

## Regras Essenciais

Pratique somente em:

- Máquinas próprias.
- Ambientes locais.
- Laboratórios controlados.
- Sistemas deliberadamente vulneráveis.
- Plataformas educacionais.
- Ambientes com autorização expressa.

Não use estes materiais para testar redes, sites, contas ou sistemas de terceiros.

## Como Usar

1. Leia [SAFETY.md](SAFETY.md).
2. Comece pelo laboratório `00`.
3. Registre objetivo, passos, resultado e dúvidas.
4. Limpe ou encerre o ambiente ao final.
5. Compartilhe aprendizados sem expor dados sensíveis.

## Formato dos Laboratórios

Cada laboratório deve conter:

- Objetivo.
- Nível.
- Pré-requisitos.
- Ambiente autorizado.
- Ferramentas.
- Passos.
- Perguntas de reflexão.
- Resultado esperado.
- Encerramento ou limpeza.
- Limites éticos e legais.
