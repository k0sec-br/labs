# Contribuindo com Laboratórios

## Objetivo

Melhorar laboratórios educacionais mantendo segurança, legalidade e clareza para iniciantes.

## Boas Contribuições

- Corrigir passos confusos.
- Adicionar perguntas de reflexão.
- Melhorar orientações de limpeza.
- Sugerir exemplos estáticos.
- Reforçar limites éticos.
- Melhorar acessibilidade da documentação.

## Conteúdo Proibido

- Ataques contra terceiros.
- Alvos reais.
- IPs públicos para teste.
- Malware.
- Persistência.
- Evasão.
- Roubo de credenciais.
- Destruição de dados.
- Engenharia social contra pessoas reais.
- Varreduras indiscriminadas.
- Instruções de invasão não autorizada.

## Formato Recomendado

Cada laboratório deve conter:

- Objetivo.
- Nível.
- Pré-requisitos.
- Ambiente autorizado.
- Ferramentas.
- Passos.
- Perguntas de reflexão.
- Resultado esperado.
- Encerramento ou limpeza.
- Limites éticos e legais.

## Pull Requests

1. Crie uma branch a partir de `develop`.
2. Faça mudanças pequenas.
3. Revise comandos e riscos.
4. Execute `git diff --check`.
5. Abra PR para `develop`.
