# 04 — Identificação de Phishing

## Objetivo

Praticar análise defensiva de mensagens suspeitas usando exemplos fictícios.

## Nível

Iniciante.

## Pré-Requisitos

- Noções básicas de e-mail, links e domínios.
- Leitura de [SAFETY.md](../SAFETY.md).

## Ambiente Autorizado

Somente exemplos fictícios criados para estudo. Não interaja com links reais suspeitos.

## Ferramentas

- Editor de texto.
- Navegador apenas para pesquisa segura.

## Exemplo Fictício

```text
Assunto: Sua conta sera bloqueada hoje

Ola,

Detectamos uma falha urgente. Acesse http://seguranca-conta-exemplo.invalid/login
e confirme seus dados imediatamente.

Equipe de suporte
```

## Passos

1. Leia a mensagem fictícia.
2. Identifique sinais de urgência.
3. Observe erros de linguagem ou tom estranho.
4. Analise o domínio sem acessá-lo.
5. Liste quais dados a mensagem tenta coletar.
6. Escreva uma resposta defensiva: o que orientar a uma pessoa que recebeu isso?
7. Registre como verificar canais oficiais sem clicar no link.

## Perguntas de Reflexão

- Que elementos tentam gerar pressão?
- Por que não devemos clicar em links suspeitos?
- Como confirmar uma comunicação por canal oficial?

## Resultado Esperado

Você deve reconhecer sinais comuns de phishing e saber orientar alguém de forma defensiva.

## Encerramento ou Limpeza

Apague exemplos se desejar. Não armazene mensagens reais com dados pessoais.

## Limites Éticos e Legais

Este laboratório é exclusivamente defensivo. Não crie campanhas reais, não envie mensagens enganosas e não colete dados de pessoas.
